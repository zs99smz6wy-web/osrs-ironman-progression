# Guide Consultations

Store a consultation only when its answer materially changes project evidence,
a merge decision, or an unresolved dependency. Prefer updating the relevant
research ledger directly and linking the consultation rather than duplicating
large responses.

Use filenames such as `opening-log-pipeline.md` or
`pre-cg-progression-conflict.md`.

Each record should contain:

- consultation ID and date;
- bounded question;
- guide sections consulted;
- compact answer with source step references;
- accepted evidence;
- rejected or unverified claims;
- resulting repository decisions or open questions.

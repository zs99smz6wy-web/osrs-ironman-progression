# Fresh-Account Guide Comparison

This directory studies how established guides leave Tutorial Island. These guides are proven route implementations followed by players and iterated when steps fail or create friction. They are strong empirical strategy evidence, though current mechanics still require factual sources.

## Comparison labels

- `shared`: both guides use the same objective or closely related bundle.
- `bruhsailer-only`: present only in the reviewed BRUHsailer opening.
- `b0aty-only`: present only in the reviewed B0aty opening.
- `different-timing`: both use it, but at materially different times.
- `current-fact-check-needed`: mechanics, prices, items, or access need primary-source validation.
- `strategy-candidate`: worth testing against this project's account state and philosophy.
- `reject-or-optional`: conflicts with the project's risk, enjoyment, evidence, or fixed-assumption boundaries.

Agreement identifies a field-tested baseline candidate. A guide-specific step is also serious evidence when its surrounding assumptions match this project. The model bears the burden of explaining any deviation; novelty is not an advantage.

Every adopted step still needs:

- a current factual source;
- exact skill, quest, item, GP, inventory, and risk gates;
- a downstream purpose;
- a reason to do it now rather than later;
- an alternative when the efficient method is brittle, unpleasant, or assumption-heavy.

A deviation from both guides must record at least one concrete reason: changed game mechanics, different account mode or risk policy, different downstream goal, better verified dependency coverage, lower inventory/GP pressure, or a deliberate enjoyment tradeoff. Unexplained simplification is not acceptable.

The final player-facing wording follows `route/guide-writing-style.md`. Detailed analysis remains here and does not belong in step text.

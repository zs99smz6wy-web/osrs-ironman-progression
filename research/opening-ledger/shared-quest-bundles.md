# Shared first-Varrock quest bundles

Research-only factual ledger. This file records current quest gates and bounded
handoffs used by both opening-guide baselines. It does not select an order,
recommend a faction, or prescribe a route.

**Source check:** source URLs were checked in the opening-guide research pass on
2026-08-25; the relevant current Wiki pages were re-opened on 2026-08-26.
Jagex's official Mahogany Homes launch post is used only as release context;
current mechanics and quantities come from the current Wiki pages.

## State policy

- A **useful resume point** is a non-repeatable quest handoff that either holds
  a cross-location instruction, a player-supplied-input boundary, a social
  dependency, or a permanent unlock.
- A **journal-only checkpoint** may be visible in-game but is not useful enough
  to persist in the account model by itself.
- Finished quests may be imported from RuneLite. The importer does not infer
  partial stages from inventory, so an item alone never proves one of these
  checkpoints.

## Children of the Sun

| Field | Verified fact |
| --- | --- |
| Start | Speak to Noah or Alina in Varrock Square. |
| Formal gates | Members; no skill, quest, item, GP, inventory-space, or combat gate. |
| Bounded checkpoints | Start investigation -> follow the suspicious guard -> report to Sergeant Tobyn -> identify four suspicious guards -> final dialogue/cutscene. |
| Useful resume points | **Completion only.** The intermediate stages have no external input or independent account capability. |
| Hazards | No enemies or required combat. The follow segment is an observation/following interaction, not a combat or inventory gate. |
| Fixed reward | 1 Quest Point. |
| Permanent unlock | Access to Varlamore. This does not grant the internal Quetzal network; see the resolved model note below. |
| Downstream factual gates already in repo | Children of the Sun is a hard prerequisite for Perilous Moons, Mastering Mixology entry, and wealthy-citizen pickpocketing records. |

## Daddy's Home

| Field | Verified fact |
| --- | --- |
| Start | Speak to Marlo at the Varrock Estate Agent building in north-east Varrock. A saw is on the floor in the same building. |
| Formal gates | Members; no skill, quest, or combat requirement. |
| Completion material gate | 10 regular planks; 5 bolts of cloth; at least 16 nails of any type; hammer; saw. Oak, teak, and mahogany planks do not work. Nails may bend, so the current Wiki recommends bringing more, and specifically 100 at level 1 Construction. |
| GP gate | Five bolts of cloth cost 650 coins each at the sawmill: **3,250 coins** if bought there. The waxwood planks are made free by the sawmill operator during this miniquest. No formal starting fee exists. |
| Inventory gates | No fixed whole-quest slot count. Keep room for the saw and three waxwood logs/planks during the relevant stages; the exact loadout depends on nails, planks, and cloth carried. |
| Bounded checkpoints | Marlo contacted/saw available -> Old Man Yarlo has been contacted and old furniture removed -> Yarlo's crates searched for 3 waxwood logs -> waxwood logs exchanged for 3 waxwood planks -> all furniture built -> reward claimed from Marlo. |
| Useful resume points | **Waxwood logs received** and **waxwood planks received** are useful procurement handoffs. **Completion** is the durable account-state point. Merely taking the saw and the furniture-removal state are journal-only unless a future execution segment needs them. |
| Hazards | No enemies or required combat. |
| Fixed reward | 400 Construction XP on completion plus 544 Construction XP from the furniture: **944 total Construction XP**. |
| Permanent reward | A Rimmington player-owned house if the account has none; otherwise 1,000 coins. Marlo's crate contains 25 planks, 50 mithril nails, 5 steel bars, 10 oak planks, 8 bolts of cloth, 5 house teleports, and 1 Falador teleport. |

Sources: [current Wiki miniquest page](https://oldschool.runescape.wiki/w/Daddy%27s_Home),
[current Wiki Construction training page](https://oldschool.runescape.wiki/w/Construction_training),
[official Mahogany Homes launch post](https://secure.runescape.com/m=news/mahogany-homes?oldschool=1).

## Demon Slayer

| Field | Verified fact |
| --- | --- |
| Start | Speak to Gypsy Aris/Aris Maye at the Varrock Square tent and pay 1 coin. The dialogue reveals a player-specific banishment incantation; Aris can repeat it if needed. |
| Formal gates | No skill or quest requirement. Completion requires defeating Delrith, level 27, while nearby Dark wizards can interfere. Silverlight is required for the fight. |
| Required inputs | 1 coin, a bucket of water, and 25 **unnoted** bones. A bucket can be obtained in Varrock Palace during the quest. Food and armour are recommendations, not formal inputs. |
| Inventory gates | Keep at least one free slot for the sewer key and another for each key/Silverlight handoff. The 25 bones occupy 25 slots before Traiborn accepts them; banking keys before collecting bones is a valid inventory-management choice, not a quest requirement. |
| Bounded checkpoints | Aris consulted -> Sir Prysin requests three keys -> Captain Rovin key received -> water used on palace drain and rusty sewer key recovered -> 25 bones delivered to Wizard Traiborn -> three keys exchanged for Silverlight -> Delrith banished. |
| Useful resume points | **Sir Prysin's three-key request**, **each externally sourced key**, and **Silverlight received** are useful cross-location or combat-preparation handoffs. The incantation is recoverable from Aris, so it is not a durable state requirement. |
| Hazards | Delrith level 27; three level-20 and two level-7 Dark wizards are part of the stated completion threat. A player must manage the surrounding attackers before/while fighting Delrith. |
| Fixed reward | 3 Quest Points and Silverlight. No skill XP reward. |
| Permanent/unlocked follow-up | Silverlight can be recovered from Sir Prysin for 500 coins if lost. The quest is a prerequisite for Shadow of the Storm and later Defender of Varrock chains. Historian Minas has a separate 5-Kudos claim after completion. |

Sources: [current Wiki quest page](https://oldschool.runescape.wiki/w/Demon_Slayer),
[current Wiki quick guide](https://oldschool.runescape.wiki/w/Demon_Slayer/Quick_guide),
[current Wiki speedrun guide, useful for current start-name confirmation](https://oldschool.runescape.wiki/w/Demon_Slayer/Speedrun_guide).

## Vampyre Slayer

| Field | Verified fact |
| --- | --- |
| Start | Speak to Morgan in Draynor Village, north of Ned's house. |
| Formal gates | No skill or quest requirement. Completion requires defeating Count Draynor, level 34, who has very high health regeneration. |
| Required inputs | Hammer, beer, garlic, and stake. Garlic is in Morgan's upstairs cupboard; Dr Harlow gives the stake after receiving beer. A hammer costs 1 coin at the nearby Draynor general store; beer costs 2 coins at the Blue Moon Inn if not already held. |
| GP/inventory gates | Up to **3 coins** if buying both hammer and beer. No fixed inventory-space requirement beyond space for the quest items and combat supplies. |
| Bounded checkpoints | Morgan consulted -> garlic acquired -> Dr Harlow has received beer and given the stake -> Count Draynor defeated. |
| Useful resume points | **Stake received** is the useful cross-location handoff. Garlic is freely recoverable; Morgan's start dialogue alone is journal-only. |
| Hazards | Count Draynor level 34. Bring combat gear and food as player-selected preparation. The hammer, garlic, and stake must be in inventory for the final encounter; the stake need not be used manually. |
| Fixed reward | 3 Quest Points and 4,825 Attack XP. |
| Permanent/unlocked follow-up | Direct prerequisite for Sins of the Father. Count Draynor becomes available in Nightmare Zone after completion. |

Sources: [current Wiki quest page](https://oldschool.runescape.wiki/w/Vampyre_Slayer),
[current Wiki quick guide](https://oldschool.runescape.wiki/w/Vampyre_Slayer/Quick_guide).

| Required inputs | 100 coins; bucket of milk; and either a seasoned sardine, or a raw sardine plus doogle leaves. Doogle leaves spawn behind Gertrude's house. |

| Fixed reward | 1 Quest Point, 1,525 Cooking XP, first kitten, chocolate cake, and stew. |
| Permanent/unlocked follow-up | Required for Icthlarin's Little Helper and Recipe for Disaster's Evil Dave subquest. ## Shield of Arrav

| Field | Verified fact |
| --- | --- |
| Start | Speak to Reldo in the Varrock Palace library, read the Shield of Arrav bookcase, then speak to Reldo again. |
| Formal gates | No skill or quest requirement. Completion needs a trustworthy player on the opposite gang path. The official in-game chat channel documented by the Wiki is `OSRS SOA`; partner coordination is a hard external dependency, not a GP substitute. |
| Faction and input gates | **Phoenix:** pay Baraek 20 coins, join via Straven, kill Jonny the Beard (level 2) for the report, receive weapon-store key, and take the left shield half. **Black Arm:** no stated coin gate; obtain two Phoenix crossbows using a Phoenix partner's weapon-store key, then defeat Weaponsmaster (level 23) or have a partner do so, and take the right shield half. Food/weapon are recommended for Black Arm, not formal global requirements. |
| Completion handoff | Give the shield half to Curator Haig Halen for two half-certificates; exchange one with the opposite-path partner; combine the certificate; give it to King Roald. Ironmen must use the key/certificate on each other rather than trade normally. |
| Inventory gates | No global fixed slot count. Preserve room for the shield half/certificate components. A player who completed the quest cannot newly obtain their gang's shield half for another player; dropped/lost half-certificates can be reacquired from the relevant storage while unfinished. |
| Bounded checkpoints | Reldo/book/reported -> faction selected -> own gang's shield half secured -> half-certificate pair received -> completed certificate assembled -> King Roald reward. |
| Useful resume points | **Faction selected** is durable and decision-relevant. **Own shield half secured** and **certificate-half exchange pending** are useful social handoffs. Treat all partner observations as player-confirmed; no inventory state proves the partner can still supply the reciprocal item. |
| Hazards | Weaponsmaster level 23 on Black Arm; Jonny level 2 on Phoenix. The more consequential hazard is an untrusted partner/scam risk during coordination. |
| Fixed reward | 1 Quest Point and 600 coins to each completing player. |
| Permanent/unlocked follow-up | Required by Heroes' Quest and later Defender of Varrock chains. Historian Minas has a separate 5-Kudos claim after completion; the existing model records this separately and a 1,000-XP level-20+ lamp from that claim. |

Sources: [current Wiki quest page](https://oldschool.runescape.wiki/w/Shield_of_Arrav),
[current Wiki Black Arm detail](https://oldschool.runescape.wiki/w/Shield_of_Arrav/Black_Arm_Gang),
[current Wiki Phoenix detail](https://oldschool.runescape.wiki/w/Shield_of_Arrav/Phoenix_Gang).

## Priest in Peril

| Field | Verified fact |
| --- | --- |
| Start | Speak to King Roald in Varrock Palace. |
| Formal gates | Members; no skill or quest requirement. Completion requires killing the Temple guardian dog, level 30, without Magic, and a Monk of Zamorak, level 30. |
| Required inputs | 50 **unnoted** rune essence and/or pure essence, in any mix; one empty bucket; combat equipment; and one free inventory slot for the key transition. Rune Mysteries is not a formal quest requirement, but is a factual access path to mine rune essence through Aubury. |
| Inventory gate | A normal 28-slot inventory cannot carry 50 essence at once. Runecrafting pouches reduce the number of trips; without them, deliveries may take multiple trips. The 50 essence are consumed. |
| Bounded checkpoints | King Roald request -> Temple Guardian defeated and Roald re-contacted -> Drezel located/Monk golden key obtained -> iron key and murky water obtained -> Drezel blesses water -> blessed water used on coffin -> Drezel requests 50 essence -> essence delivered. |
| Useful resume points | **Drezel requests 50 essence** is the useful procurement handoff. **Completion** is the only permanent regional-access point. Earlier combat/key stages are journal-only unless an execution segment uses them as a local stop. |
| Hazards | Temple guardian is immune to Magic. The Monk attacks with Magic. Both can be safespotted or flinched under the current Wiki guidance. Low-level food/escape planning remains player-selected. |
| Fixed reward | 1 Quest Point, 1,406 Prayer XP, Wolfbane, and Morytania access. |
| Permanent/unlocked follow-up | Direct prerequisite for Nature Spirit and Ghosts Ahoy; factual regional gate for Morytania diaries, Barrows entry, and several Morytania teleports. Historian Minas has a separate 5-Kudos claim after completion. |

Sources: [current Wiki quest page](https://oldschool.runescape.wiki/w/Priest_in_Peril),
[current Wiki quick guide](https://oldschool.runescape.wiki/w/Priest_in_Peril/Quick_guide),
[official 2016 poll documenting Priest in Peril teleport gates](https://oldschool.runescape.com/polls/2016/1294).

## Integration boundary

This ledger supports later partial-quest modelling. It does **not** authorize
adding milestones, actions, graph edges, or execution steps. The strongest
future candidates are the explicitly marked useful resume points, subject to
the existing `quest_not_completed` guard pattern and player confirmation.
